# 1-Environnement

## Exercice 1

### Les targets :

C'est les différentes distributions.

### Les fichiers de base :

Ils représentent la structure de base de l'application.

### Le dossier Assets :

C'est le dossier qui permet de changer tout ce qui est AppIcon, on y range toutes nos images etc...

### Le Storyboard :

C'est une vue, un écran qui affiche le rendu visuel de notre code.

### Le Simulateur :

C'est une "application" qui permet de simuler un iphone ou ipad ou autre, afin de tester l'application.

## Exercice 2

### Cmd + R :

Ce raccourci permet de build et de lancer le simulateur.

### Cmd + Shift + O

Ce raccourci permet de rechecher quelque chose dans le projet.

### Indentation auto

Le raccourci est Ctrl + I.

### Commenter

Le raccourci est Cmd + /.
